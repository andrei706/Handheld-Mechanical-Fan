# Handheld Mechanical Fan

This handheld fan is a portable, battery-free cooling device powered by a manual trigger-action lever. By pulling the lever, a set of gears inside spins the fan blades at high speed which gives you an instant breeze from a simple squeeze.

This repository will contain the fusion files with the assembly and STL files needed for 3D printing.

## Pieces used
- Main housing (upper and lower shell) for holding everything together
- Action lever to start the motion
- Connecting bar with two holes to link the lever to the Drive gear
- Drive gear which receives power directly from the lever
- Two intermediate gears which step up the speed of the rotation
- Pinion gear which will spin the propeller
- Propeller which is the functional output of the device that moves the air to create a breeze

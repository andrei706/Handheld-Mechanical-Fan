# Handheld Mechanical Fan
<img width="1253" height="659" alt="image" src="https://github.com/user-attachments/assets/aa3abb43-2910-4b40-99ec-0d936fa22a10" />

This handheld fan is a portable, battery-free cooling device powered by a manual trigger-action lever. By pulling the lever, a set of gears inside spins the fan blades at high speed which gives you an instant breeze from a simple squeeze.

This repository contains the `.f3d` design files, `.gcode` files and STL `.stl` needed for 3D printing.

[![Watch the demo which showcases the functionality of the device](https://img.shields.io/badge/YouTube-Video_Demo-red?style=for-the-badge&logo=youtube)](https://youtu.be/0PXK0Q6173k)

## Pieces
- **Main housing:** Upper and lower shell halves that enclose and secure the internal mechanisms.
- **Action lever:** The trigger mechanism used to power the fan manually
- **Connecting bar:** A dual-holed linkage arm that transfers linear motion from the lever to the Drive Gear.
- **Drive gear:** The primary driving gear that directly interfaces with the lever linkage.
- **Two intermediate gears:** Compound gears responsible for stepping up the gear ratio to maximize RPM.
- **Pinion gear:** The final high-speed gear that drives the propeller shaft.
- **Propeller:** The functional output of the device that moves the air to create a breeze
- **Propeller stand:** the coupling hub that securely mounts the propeller to the pinion gear shaft.
